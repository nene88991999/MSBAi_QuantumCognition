# Collection Plan Freeze

M4S2 · 90 minutes

Watch the videos before the meeting. Bring the repaired pilot, exact prompts, six-condition design, collector settings, analysis plan, thresholds, and contribution log.

**Work to take away:** A dated frozen collection plan, a replayable pilot, named responsibilities, and a deviation-log template.

## 0–10 Minutes · From Proposal to Collection

| Completed | To decide now |
| --- | --- |
| Week 3 proposal | Exact implementation |
| Pilot and repairs | Unresolved exception handling |
| Planned interpretation | Stopping and analysis rules |

Can the team run the same plan independently?

The freeze makes the planned procedure concrete before main outcomes are observed. Canvas provides the submission date and any instructor sign-off process. Do not invent a required new approval that is absent from the course instructions.

## 10–25 Minutes · The Frozen Record

| Decision | Record to retain |
| --- | --- |
| Prompts and conditions | Exact text and context rules |
| Sampling and collection | Persona grid, repetitions, stopping rule |
| Analysis and thresholds | Coding, exclusions, uncertainty, tolerances |

Find one field that another person could interpret differently.

Use the existing collection guide. Freeze model version and settings where controllable; document version changes that the provider imposes. Retain access and cost constraints. Establish what happens when calls fail or budget limits are reached.

## 25–40 Minutes · Test Exceptions before Collection

| Event | Rule to specify |
| --- | --- |
| Malformed answer | Parse, retry, or mark invalid |
| Interrupted run | Resume without duplicate records |
| Model version changes | Document and assess comparability |

Write the rule before a real exception occurs.

Run a small demonstration of one failure case. Preserve the original attempt and any retry. An exception rule must not condition on whether the result favors the hypothesis. Avoid collecting credentials in the shared document.

## 40–60 Minutes · Exchange and Replay a Pilot

Give another team a complete pilot record.

Ask them to reconstruct order and denominator.

Resolve disagreements in the written protocol.

A peer replay checks reproducibility rather than grading the team’s substantive conclusion. Confirm that peers can identify the intended unit of analysis and the context retained for each arm. Use supplied data if access is limited.

## 60–80 Minutes · Responsibilities and Deviations

| Work | Named owner | Review |
| --- | --- | --- |
| Collection and logs | Team assigns | Second member checks |
| Analysis and figures | Team assigns | Second member reproduces |
| Deviation record | Team assigns | Reason and effect retained |

Set responsibilities without isolating knowledge in one member.

Each student remains responsible for understanding the audit for the individual defense. The deviation log records date, reason, affected records, and consequences. A necessary repair after the freeze remains visible and may narrow the claim.

## 80–90 Minutes · Freeze the Plan and Open Collection Next Week

Save the dated collection-ready version.

Collect in Weeks 5–6 under that version.

Keep new agency examples separate from the frozen study.

Week 5 opens the collection window. Week 6 closes it. Week 7 supports analysis and peer critique; Week 8 holds presentations and individual defenses. The new philosophy material can improve interpretation without adding unplanned experimental arms.
