## 0–20 Minutes · Compare the Same Target Question

| Category | Target answer probability |
| --- | --- |
| B alone | 80.0% |
| B after A | 55.0% |

Constructed practice values; no sampling uncertainty is supplied.

What is the difference, and which denominator is used?

Fresh teaching values distinct from the lecture construction. Difference is 25 percentage points. The second bar includes all respondents reaching B, not only those giving a particular first answer. Before interpreting, specify comparable populations, wording, information, and uncertainty.

Source basis: Nathan Yang, Free Will and a Choice-Theoretic Separation of Classical and Quantum Models, September 2026 revision; course philosophy primer. Background: Christian List, Decision Theory Presupposes Free Will (2024), https://philpapers.org/archive/LISDTP.pdf; Herman Cappelen, Introduction to Conceptual Engineering (2018), https://academic.oup.com/book/25598/chapter-abstract/192942115.

## 20–40 Minutes · Two Explanations for the Same Pattern

| Explanation | What changes after A? |
| --- | --- |
| Quantum updating | The modeled evaluation state |
| Classical memory process | A stored state or response rule |

Propose an observation on which predictions could differ.

Have one group describe a quantum account and another a memory account. Require a pre-specified prediction for a longer history or independent measure. A direct-versus-sequenced difference rejects a non-invasive fixed-response benchmark under the stated conditions, while state-changing classical processes remain possible.

## 55–70 Minutes · Resolve a Collection Issue

Identify the affected records.

Apply the frozen exception rule.

Document any necessary deviation and its consequence.

Use the agreed protocol, not a newly optimized response rule. Review duplicate IDs, malformed answers, and missing required arms. If a change affects comparability, retain separate labels and plan a sensitivity check.

## 70–85 Minutes · Build a Defensible Evidence Table

| Claim | Evidence | Remaining assumption |
| --- | --- | --- |
| Target response changed | Estimate and interval | Comparable procedures |
| A benchmark fails | Named restriction | Preparation conditions |
| Agency interpretation | Reasons and control | Additional evidence identified |

Peer-review one row of another team’s table.

The table is a report component. A report should not claim free will from an order effect or consciousness from language-model fluency. Distinguish a model result from human evidence. Review the paragraph begun in M5S1.
