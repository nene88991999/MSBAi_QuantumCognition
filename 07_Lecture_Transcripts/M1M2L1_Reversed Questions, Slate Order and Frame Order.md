# M1M2L1_Reversed Questions, Slate Order and Frame Order

Welcome to Module 2. In Module 1 we saw that the order of questions can change people's answers, and we met a picture of how a quantum model explains that.

This module is about order effects: how to spot them, how to measure them properly, and what to do about them. Let's start with a situation you could find in almost any company.

Two committees with similar members review the same proposed store. They get the same information and use the same criteria.

The only difference is the order of the questions. One committee first asks whether the location has a strong market, and then whether it fits the brand.

The other asks about brand fit first. Suppose the two committees approve the store at different rates.

When changing the order of questions changes the answers like this, we call it an order effect. If members were assigned to the committees by chance, which is what random assignment means, we can be fairly confident the order caused the difference.

What random assignment can't tell us is why the order mattered. Maybe members learned something from the first question, stuck with an earlier answer, or saw the store differently depending on which question came first.

To figure out why, we need a starting point to compare against. Our benchmark is something called order invariance, which is a formal way of saying that reversing the questions shouldn't change the overall pattern of answers.

Here's an everyday example. Picture a dashboard showing a store's revenue and its costs.

If you click on revenue first, the cost figure doesn't change. Both numbers were already there.

A fixed-judgment model, the classical model from Module 1, treats survey questions the same way: each question just reads an opinion that's already settled. So one table of answers should describe both orders.

Now, two groups of people will never give exactly the same percentages, just by chance. That natural wobble is called sampling variation.

If the two orders differ by more than sampling variation can explain, something else is going on. Classical models of learning and quantum models of judgment give us different explanations to test.

To run that test, we need to keep more than the headline numbers. With two yes-or-no questions, each person gives one of four answer pairs: yes to both, yes to A only, yes to B only, or no to both.

We build a table of those four pairs for each order, using the same labels for A and B in both tables, and we keep each person's two answers together. Why bother?

Because a single number, like the overall approval rate, can hide what's really changing underneath. Two orders might produce the same approval rate while the pattern of answer pairs looks quite different.

The QQ equality, which we'll study in this module, depends on those pairs, so keeping them is essential. Later, when we design a full audit, we'll also record one more thing: the final decision, such as whether to approve the store.

So why might the answer pairs change? Recall the construction idea from Module 1: the first judgment can help form the next one.

Imagine a committee member who thinks about market strength first. Her mind is on growth by the time she considers brand fit.

Another member starts with brand fit, so she's thinking about whether the store suits the existing business, or whether it might take sales from nearby stores. They're looking at the same evidence, but they give it different weight.

There's a mathematical name for this: non-commutativity. It sounds intimidating, but it just means that doing A and then B can give a different result from doing B and then A.

Putting on your socks and then your shoes is not the same as shoes and then socks. In the next lesson, we'll use the arrow picture to show exactly what non-commutativity looks like.

Before we can fix an order effect, we need to know which kind we're dealing with, because there are two. An order effect can happen between whole items, not just between questions.

The first kind is slate order, which simply means the order of items on an agenda. Let's look at Calloway Home, a company I've made up for this course.

Its reviewers consider twelve possible store sites in one sitting. A site with a given score gets approved 71 percent of the time when it comes right after a weak site, but only 48 percent of the time when it follows a flagship.

That's a gap of 23 points for the same kind of site. Why?

Because the previous site becomes a comparison point. After a weak site, an average one looks good.

After a great one, it looks disappointing. Explaining a judgment by what it's being compared with is called a contrast account.

Here, the comparison point keeps changing as the agenda moves along.

So how do you fix a slate effect? You change how the agenda is set up and how each item is scored.

First, shuffle the agenda at random, so a site's position has nothing to do with how good it is. Second, score each site against fixed standards set ahead of time, instead of comparing it with whatever came before.

Third, build in breaks, because tired reviewers tend to drift. And fourth, average across independent reviewers who each see a different order.

Notice that none of these steps changes the decision criteria themselves. They aim to reduce changes in the comparison point and the effect of fatigue.

Then you run the test again. If the previous site, or a site's position on the agenda, no longer makes much difference, the fix is working.

The second kind of order is the one we met with the committees at the start: frame order, meaning the order of questions about a single item. For each site, the committee asks whether the trade area is strong and whether the site fits the brand.

Starting with market strength may point attention toward growth, while starting with brand fit may point it toward how the site suits the existing business. Same evidence, different priorities.

This next point matters for managers. Because both questions are about the same site, shuffling the order of sites won't fix this.

The slate fix leaves frame order untouched, which is exactly what the graphic shows. To understand a frame-order effect, the audit has to compare different explanations, such as incompatibility and learning.

A common way to handle frame order is to balance it, and it's worth being clear about what that does and doesn't do. Picture ten evaluators.

Five get trade area first, and five get brand fit first. The assignments are balanced, but each evaluator still follows only one path.

No one follows both paths. So balancing lets you measure how sensitive the decision is to order, by comparing the two groups.

What it doesn't do is take order out of anyone's decision. Averaging the two groups just blends two different procedures together.

If the audit suggests construction is going on, leaders have to decide which procedure actually suits the task. They might test one standard order, let reviewers look at both frames before answering, or create a single shared scoring rule.

Since the two kinds of order come from different processes, a good audit tests them separately, with two separate random assignments. First, it shuffles the order of the candidate stores.

That tests whether the agenda changes how stores are judged. Second, for each store, it varies whether the market question or the brand question comes first, across comparable evaluators.

That tests frame order within a single item. As before, it keeps both answers so we can build the two four-box tables.

Running the two assignments separately lets us measure two different effects, and that matters because they call for different fixes. Changing the agenda can deal with contrast between stores.

Changing the question order deals with how a single store is evaluated.

Let's wrap up. On a dashboard, slate order and frame order can look alike, since both show up as answers changing with order.

But they have different causes and different fixes. Slate order changes the comparison point from one item to the next.

Frame order changes the sequence of judgments about a single item, and it may point to incompatible questions. So in any audit, keep a record of the order each person was given, every answer along the way, and the final decision.

If you keep only the final answers, you throw away the evidence you'd need to tell these two effects apart. In the next lesson, we'll go back to the arrow picture and see what happens, step by step, when two questions are asked in different orders.
