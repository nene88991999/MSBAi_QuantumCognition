# M1M2_Introduction

Welcome to Module 2. In Module 1, we saw that changing a question can change the judgment it records.

Now we'll zoom in on one specific change: the order of the questions. Picture a committee deciding whether to open a new store.

If they discuss the market opportunity first, they might reach a different decision than if they start with whether the store fits the brand. How could we investigate a difference like that in a fair way?

That's what this module is about.

We'll begin by separating two kinds of order that are easy to mix up. Slate order is the order of items on an agenda, like which store the committee reviews first.

Frame order is the order of the questions asked about one item, like whether opportunity or brand fit comes first for a given store. Shuffling the stores doesn't change which question comes first about each store.

So these two kinds of order need separate comparisons, and separate fixes.

Next, we'll return to the arrow picture from Module 1, and see why answering question A before B can give a different result than answering B before A. Then a short lesson on uncertainty will give you some tools we'll need.

You'll see how results vary from one sample to the next, how a technique called the bootstrap helps measure that variation, and how to decide in advance how big a difference has to be before it matters.

Those tools prepare us for the QQ test, which compares how often each person's two answers agree, across the two orders.

Finally, we'll put all the pieces together in an audit design. We'll choose the questions, keep every person's full set of answers, and decide in advance what each possible result would mean for the business.

The aim is to connect a clear, fair comparison to a decision the organization actually needs to make. Let's start with the two kinds of order.
