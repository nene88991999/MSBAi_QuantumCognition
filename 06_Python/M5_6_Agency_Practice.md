# Agency Practice for Weeks 5 and 6

This ungraded exercise supports the live sessions and uses constructed teaching examples. It requires no model account, API key, or philosophy background.

Open the [notebook](notebooks/M5_6_Agency_Practice.ipynb), or run `python M5_6_Agency_Practice.py` from this folder. The [CSV](data/M6_Return_Histories.csv) has 100 complete, artificial A–B–A histories. Each respondent ID identifies one paired first and return response. The middle answer is included to retain the sequence but was assigned for teaching and supplies no evidence of a psychological mechanism.

Before running the calculation, compare the initial and return off shares. Then count individual changes and explain why the two measures differ. In the welfare exercise, compare renewal probabilities of 20% and 35% when declining is worth $10 more than renewing. State the offer, value, and procedure-cost assumptions.

Keep these exercises separate from the frozen project data. They illustrate calculations and interpretation without adding collection arms or graded deliverables.
